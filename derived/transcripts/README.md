# Transcript conventions

**Status: conventions only; no actual or blind transcription is included by this file.**
Transcription depends on an inventoried recording, protected original, and documented input
version/processing. Retain source/asset IDs, hashes, time base, exact time/frame locations,
listener identity/type, date, and any missing information or prior processing.

Use `[unclear]` for uncertain audio and preserve plausible alternative readings. Separate an
audible sound from an interpretation of its words. Do not silently repair wording, invent absent
audio, or present generative enhancement as recovered evidence. Keep originals beside any
conservative listening derivative, with settings/arguments/tool versions and all input links.

For disputed passages, obtain a second transcription without exposing preferred wording. Record
the listener's actual exposure and input. The reviewer can report uncertainty or a different
reading. If a blind listener is unavailable, preserve the waiting dependency and keep the disputed
reading outside supported findings. AI agreement is not independent factual corroboration.

Future `annotated-transcript.md` should carry time-coded observations, unclear/alternative readings,
input manifest, and limitations. Future `blind-transcription.md` should preserve the independent
pass before comparison with a preferred transcript. Check quotations, names, dates, and extracted
text against underlying media before use in findings.

Recording-derived cultural interpretation follows source T07 completion and required blind review
before T08. Separately tracked preliminary availability notes do not establish recording wording.
