# Conservative audiovisual comparison

**Status: methods guide only; no recording has been analyzed by writing this file.**
Inventory and protect real inputs before detailed comparison. Media executables are conditional
dependencies of a justified question; ordinary metadata checks do not require installing them.

## Intake and lineage

Record capture date, receiver/feed, tape generation, surrounding material, completeness, edits,
prior processing, restrictions, original-media history, and digitization history, with explicit
unknowns. Separate historical capture lineage from software transformation inputs. Equal hashes
and shared clips do not create independent captures. Compare common damage, cropping, subtitles,
and edit points as evidence of possible dependence, not automatic proof of its exact history.

## Processing manifest

Every derivative retains all input AST IDs and exact locators, expected source hashes, method,
executable/version, complete arguments/settings, stream selection, time base, interlacing/timing
notes, output locations/hashes, and information lost or already absent. A multi-source derivative
retains every input rather than an arbitrary single source. Keep unchanged originals available
side by side. Confirm original backups and current-byte integrity before probing or processing.

Use only the conservative transformations needed for a bounded repeatable question. Preserve analog
timing/interlacing where present before making viewing copies. Retain raw measurements separately
from interpretation and assess repeated movement, boundaries, audio continuity, picture-quality
changes, and possible edits against copying/encoding artifacts. Hum, pitch, distortion, and defects
can arise anywhere in the chain. Generative enhancement cannot supply recovered evidence.

## Transcription and limits

Use time-coded `[unclear]` labels and alternative readings. A second listener transcribes disputed
passages without preferred wording. Record the actual listener/exposure and inspected input.
If unavailable, keep the task waiting and disputed wording outside supported findings. A second AI
reasoning check is not an independent transcription or independent factual corroboration.

Register search failures, unavailable tools/inputs, and lost information explicitly. A comparison
report must cite actual input revisions, observations, method/result, strongest alternative,
confidence/limits, and next action. Fixtures prove workflow, not incident findings or authentication.
